# 📘 構文対応 暗記カードアプリ  
**PWA 対応・iCloud/Google Drive 同期・構文モード搭載**

このアプリは、プログラミング学習に特化した **暗記カードアプリ** です。  
GitHub Pages 上で動作し、スマホ・PC どちらでも快適に利用できます。

---

## 🚀 デモ（GitHub Pages）

https://khdevworks.github.io/anki-app/

---

## ✨ 主な特徴

### 🔹 1. PWA 対応（ホーム画面アプリ化）
- iPhone / Android / PC でホーム画面に追加可能  
- オフラインでも動作  
- ネイティブアプリのような使い心地  

### 🔹 2. 構文モード（コード＋選択肢）
- コードブロック表示  
- 選択肢形式の問題  
- 通常の Q&A 形式にも対応  

### 🔹 3. ローカル JSON 読み込み
`cards.json` を読み込んで学習を開始できます。

### 🔹 4. カード保存機能（カテゴリ付き）
- 保存すると学習カードから削除  
- 保存済みカードは localStorage に永続保存  
- カテゴリ別フィルタ  
- キーワード検索  
- 再インポート可能  

### 🔹 5. 出題順ランダム化
読み込み時に自動シャッフル。

### 🔹 6. スワイプ操作（スマホ最適化）
- 左スワイプ → 次のカード  
- 右スワイプ → 前のカード  

### 🔹 7. ダークモード対応
OS のテーマに合わせて自動切り替え。

### 🔹 8. iCloud 同期（WebDAV）
- 保存済みカードを iCloud Drive にアップロード  
- iCloud Drive から読み込み  

### 🔹 9. Google Drive 同期（Drive API）
- OAuth 認証  
- Drive に保存 / 読み込み  

### 🔹 10. 自動バックアップ
カード保存時に自動で iCloud / Google Drive にバックアップ。

## 📊 Clean Architecture コンポーネント説明

| レイヤー | ファイル | 役割 |
|---------|---------|------|
| **UI層** | `index.html` | ユーザーインターフェース表示 |
| **アプリ層** | `app.js` | ユーザー入力処理、Firebase認証管理、UIイベント |
| **ユースケース層** | `usecases/cardUseCases.js` | ビジネスロジック、同期ロジック |
| **リポジトリ層** | `db.js` | データソース抽象化、同期判定 |
| **ローカルDS層** | `db.js` (DexieLocalCardDataSource) | IndexedDB操作 |
| **リモートDS層** | `firebaseCardDataSource.js` | Firestore操作 |
| **PWA** | `manifest.json`, `service-worker.js` | ホーム画面アプリ化、オフライン対応 |

## 🔄 主要なデータフロー

### 1. カード作成フロー
```
ユーザー入力 → createCard() → ユースケース層 
→ CardRepository → Dexie(IndexedDB)
```

### 2. Firebase同期フロー
```
Firebase ← cardRepository.syncToRemote() 
← cardUseCases.syncToRemote() ← UI「ローカル → Firebase 同期」ボタン
```

### 3. Firestore読み込みフロー
```
Firestore → firebaseCardDataSource.readCards() 
→ cardRepository.syncCards() 
→ cardUseCases.syncCards() 
→ IndexedDB保存 → UI更新
```

## 📦 セットアップ方法

### 1. リポジトリをクローン

```bash
git clone https://github.com/KHDevWorks/anki-app.git
cd anki-app
```

### 2. Docker で起動（推奨）

Docker と Docker Compose がインストールされていることを確認してください。

```bash
# イメージをビルドして起動
docker-compose up --build

# ブラウザでアクセス: http://localhost:8080
```

開発時はボリュームマウントにより、ファイル変更が即座に反映されます。

### 3. 手動セットアップ（オプション）

Docker を使用しない場合は、ローカル HTTP サーバーで `index.html` を提供してください。

- `app.js` の `firebaseConfig` に Firebase 設定を追加
- Firebase Console で Email/Password 認証を有効化
- Firebase Console の許可済みドメインに `http://localhost:8000` と `http://127.0.0.1:8000` を追加
- Dexie.js は CDN から読み込まれます
